# let's clap · 一起拍手吧：语音提示文案

当前产品仍为两个页面；下表是各页面内的交互步骤。首次点麦克风开启语音互动，之后讲完自动收听、回答停顿约 1.2 秒自动提交。可暂停语音；点选入口作为后备。名字、开始录音、保留作品需要明确点击确认。

| 页面 | 步骤 | 当前口播原文 | 后续动作 |
|---|---|---|---|
| 宠物页 | 选择性格 | 你希望小伙伴是什么性格？欢快、安静，还是搞怪？ | 回答偏好 → AI 匹配三种性格 → 孵化 |
| 宠物页 | 三小节唤醒 | 小手掌亮起来时，跟着拍一下。一起拍三小节，唤醒小伙伴吧！ | 不录音；按知识库节奏拍三小节，之后破壳、旋转一圈 |
| 宠物页 | 取名字 | 我醒啦！你想给我取什么名字？ | 说出名字 → 显示候选，不直接保存 |
| 宠物页 | 确认名字 | 喜欢这个名字吗？点一下确认名字，我们就可以一起玩啦！ | 点击确认名字后保存 |
| 宠物页 | 已孵化首页 | 今天想和我去大风车探险吗？你可以说，我们去探险吧！ | 说“我们去探险吧” → 探险页 |
| 探险页 | 发现风车 | 哇！前面有一个大风车！我们一起去看看吧！ | 讲解后自动进入心情提问 |
| 探险页 | 选择心情 | 看到大风车，你是什么心情呀？开心、平静，还是兴奋？ | 回答心情 → AI 匹配开心/平静/兴奋 → 合法编排 |
| 探险页 | 编排等待 | 让我把你的心情，变成一段拍手节奏。 | 等待真实编排；失败使用明确标记的规则后备 |
| 探险页 | 两小节示范 | 先听我拍一遍。小手掌亮起来的地方，就是拍手的位置。 | 讲完自动播放两小节节奏 |
| 探险页 | 示范后互动 | 想试试吗？也可以告诉我，简单一点、慢一点，或者再听一次。 | 说简单一点/难一点/慢一点/再听一次；准备好了 → 开始提示 |
| 探险页 | 确认开始挑战 | 准备好了，就点开始挑战。戴上耳机，我们把拍手声录下来。 | 点击开始挑战才录拍手 |
| 探险页 | 录音前说明 | 先听四拍，再轮到你。看着亮灯拍手，我会安静地听。 | 讲完申请拍手麦克风；四拍倒数后录两小节，关闭对话收音 |
| 探险页 | 真实录音分析 | 拍手录好啦！让我听听你的节奏。 | 实际 PCM 起始点检测与匹配；不说虚构评价 |
| 探险页 | 反馈后的选择 | 想再练一次，还是听听自己的拍手？也可以点保留这次。 | 可说再练一次/听我的拍手/保留这次；保留只提示点击 |
| 探险页 | 确认保留作品 | 喜欢这次拍手，就点保留这次，我们一起听听你的作品。 | 点击保留这次才保存作品 |
| 探险页 | 作品试听 | 这是你的大风车拍手片段！想听听吗？你也可以说，再练一次。 | 说听听我的作品 → 真实拍手与旋律混音；可说再练一次 |
| 通用 | 没有听清 | 我还没听清。准备好时，再点一下麦克风告诉我吧。 | 暂停收音；点击麦克风重新开始 |

## 动态口播

- 名字候选：你想叫我{名字}吗？喜欢的话，点确认名字吧。
- 分析不可靠：这次没有听清每一下拍手。我们再试一次吧。
- 检测到漏拍：有些位置没听到拍手。看着亮起来的节奏块，再试一次吧。
- 检测到多拍：有些位置多听到了一下。我们先听示范，再试一次吧。
- 无上述问题、设备未校准：拍手录好了！先听听自己的演奏吧。
- 只有设备延迟已校准且真实结果支持时，才允许早/晚反馈；当前默认未校准。

## 修改位置

固定口播统一在 src/app/prompts.js。修改后用 scripts/render-prompts.mjs 重新生成对应 WAV（PROMPT_ID 指定步骤，REGENERATE=1 覆盖），运行本脚本更新文档。动态名字与实际分析反馈只播放通过原文校验的千问音频，失败保留文字，不生成假结论。
