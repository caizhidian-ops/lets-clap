# 毛绒动物角色 v2

用户本轮明确要求贴合参考中的熟悉动物，只微改，避免幻想生物；v2 改为鲸鱼、企鹅、腊肠狗。保留动物基本解剖与圆胖软玩偶比例，在配色、脸部和绒布处理上做调整。参考图片仅观察，未上传给 Tripo。

本轮仅创建三次 Tripo text-to-model 任务，v3.1 标准几何/PBR 纹理、30000 面上限。脚本 `scripts/tripo-plush-v2.py`；冻结提交记录放 `.asset-jobs/plush-v2`，资产与来源放 `public/assets/plush-v2`。上一轮模型原样保留。

## 质感处理

生成提示词要求光滑连续外轮廓、统一 2mm 短绒、方向一致的细纤维；明确排除粗绒团、鳞片、石块、塑料身体。模型自带贴图仍须以实际结果为准。

`public/plush-fur.js` 为浏览器预览额外增加十二层稀疏微纤维 shell，降低材质金属度、提高粗糙度、减弱 normal 强度。此项是实时预览效果，不写入下载 GLB。移植到游戏需要同时接入此文件；第三方软件仅打开 GLB 将看到模型原生纹理。

预览 `http://127.0.0.1:5174/plush-animals.html`，支持鼠标/触摸旋转、方向键旋转、滚轮缩放和恢复视角。静态资产，未绑定动画。

实耗 60 积分。三个 GLB 的文件头、长度、SHA-256 与内嵌纹理已核对。腊肠狗原始生成的腿偏长，保留 provider raw，导出版本整体前后轴加长 22%、高度缩短 22%，让轮廓更矮胖；此比例调整已写入下载 GLB。鲸鱼仍有少量布料褶皱，不能等同于摄影级单根毛发。
