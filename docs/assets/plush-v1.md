# Let's Clap 原创 3D 毛绒资产

本轮范围：三个原创音乐怪物 + 当前项目已有的 Tripo 风车。Jellycat 图片只作为柔软短绒和胖比例的观察参考，未上传、未做图生模型。三只角色的身体、触角、尾巴和胸口音乐标记通过原创文字描述生成。

- 咚咚：杏色梨形团子，三根鼓槌状头顶绒芽，三枚拍点胸饰，无熊耳。
- 悠悠：蓝紫三瓣云团，卷尾巴，奶油月牙胸口，无鲸鳍、企鹅喙或动物耳朵。
- 蹦蹦：开心果绿圆球，叶形触角，珊瑚色螺旋胸饰。
- 风车：奶油塔、珊瑚屋顶、四色木帆，复用本项目已成功的独立 Tripo 任务。

生成脚本 `scripts/tripo-plush-v1.py`，模型 `v3.1-20260211`，标准几何/PBR 纹理，三怪物各 30000 面上限。密钥仅从本机既有配置读取，不进入公共资产；提交前落盘 intent，遇到未知结果不得重复提交。任务状态及带签名输出 URL 只放 Git 忽略的 `.asset-jobs/plush-v1`。公开模型与来源记录位于 `public/assets/plush-v1`，每个 JSON 包含 taskId、prompt、SHA-256、实际积分及文件大小。

预览：`http://127.0.0.1:5174/plush-assets.html`，拖动旋转，滚轮缩放，恢复视角，下载 GLB。预览复用项目本地 Three.js/GLTFLoader，无 CDN。

这是静态带纹理模型；毛绒为几何/贴图表现，不是动态毛发。未绑定骨骼、未验收走路动画。新怪物首先交付独立 3D 预览，不覆盖其他聊天正在修改的游戏场景。后续接入时使用独立 plush-v1 路径和来源记录，不混用旧 monster.glb。

## 本轮验证

四个 GLB 都通过长度/文件头检查、SHA-256 对照，均包含三张内嵌纹理；无需外部贴图文件。咚咚 29002 三角面、悠悠 28764、蹦蹦 29102、风车 19176。浏览器四个模型实际加载，键盘旋转与视角恢复可用，390px 手机布局无横向溢出。新任务实际消耗 60 积分；风车沿用既有 20 积分任务，未重复生成。

实际形态与提示词仍有差别：悠悠的尾巴较短，卷曲不明显，胸口月牙生成成偏黄色的立体块；另外两只的绒毛更接近簇状短绒。此版本可以用于原型资产评审，不能等同于已完成角色定稿或动画生产验收。截图 `lets-clap-tripo-originals.png` 展示实际 GLB 渲染，不是概念图。
