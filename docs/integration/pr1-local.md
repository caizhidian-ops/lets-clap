## 流程与文件

- `/` 使用 Mio 的 `src/app/main.js`：性格、三小节孵化、命名确认、探险、心情、编排、示范与难度调整。
- “开始挑战”关闭语音采集、提示和音频，将当前计划与命名宠物写入 sessionStorage，再到同源 `/practice.html`。页跳转隔离两套 CSS，并通过 pagehide 释放资源。
- `public/integration-handoff.js` 验证和映射交接；孵化宠物对应场景模型，名字不会被默认宠物名覆盖。兴奋仍未指定关卡，提示选择开心或平静。
- 游戏入口 `flow.js` 与 `interior-session.js` 接收实际 `expectedOnsetsSec`、BPM 与 planId。`jump-rope-engine.js` 按目标时间轴匹配，休止不生成目标；绳圈与动作速度跟随拍点间距。原 48 拍默认练习与旧夜行关卡保留。
- 完成后接原试听、报告、专辑墙、改名与勋章。八拍编排按音乐小节长度循环到原有 96 BPM / 30 秒伴奏，不能按稀疏目标数量循环；报告用原始游戏时间轴。
- `bobo.pet` / IndexedDB 原 Mio 作品与 `lets-clap-v1` 原专辑数据均保留，未迁移、清空或覆盖历史作品。新游戏仅记录拍点，不保存原始麦克风录音；作品中的鼓声由拍点合成。
- `server/index.js` 为统一服务，提供 Mio HTTP/WebSocket API 并复用 `server.mjs` 的报告与反馈处理。增加固定依赖 `ws@8.21.0`。运行 `./scripts/run.sh`；指定端口示例 `PORT=5199 ./scripts/run.sh`。
