# 跟拍报告与儿童成长卡

2026-10-11，基于本地 `lets-clap` HEAD `966044b523c193073126be2051231fd141d819fd` 及已有未提交改动接入。前置语音/宠物流程沿用现有实现，Mio 代码尚未合并。

## 主流程

完成游戏 → 点击「试听作品」 → 自动后台分析 → 试听页或专辑墙点击报告图标。分析与歌曲合成独立，报告失败不阻止试听和收藏；失败时显示本地建议并提供重试。报告请求绑定作品 ID，切换页面、收藏和开始新一轮不会把迟到结果写进另一首作品，也不会重建正在播放的音频。

`report-controller.js` 管理请求和状态，`report-view.js` 管理报告弹窗、课程路径与成长卡。`flow.js` 接入完成回调；`server.mjs` 提供 `POST /api/rhythm-report`。原 `POST /api/feedback` 与 `LetsClapPlayback.setResult()` 保留。

## 数据与反馈依据

引擎结果新增 `bpm, expectedTimes, toleranceMs`。实际输入 `times` 与目标 `expectedTimes` 都是相对音乐回合起点的毫秒，排除四拍准备。游戏原始成绩保持原值；报告按时间轴做逐次、唯一匹配，给出命中/漏拍/多拍、偏早/偏晚、命中平均绝对偏差，以及一条优点、一条改进建议、一个小练习。游戏与报告计数不一致时，不计入掌握。

只分析拍点，不上传原始麦克风录音。输入来源区分 `tap_demo`、`microphone_clap`、`mixed_mic_tap`。麦克风拍点仍可能有误检/漏检，报告会说明；不会根据时间点宣称看到了身体动作或听懂了音色。无输入/少量输入明确提示不足。

无 `QWEN_API_KEY / DASHSCOPE_API_KEY` 时返回明确标注的本地规则反馈。有服务端配置时调用现有 DashScope 千问接口改写教学建议；模型不决定成绩与掌握条件。真实千问仍须单独验收。CLI 已保存的凭据不会自动载入本服务，也没有将密钥写入浏览器。

## 阶段与成长卡

当前可练的是「均匀跟拍」：96 BPM，4/4 拍，48 拍，30 秒。展示后续「强弱拍 → 长短节奏 → 节奏组合」路径，三阶段明确为待开放，没有对应玩法或结业证明。

采用用户选择的儿童成长卡文案「我学会了均匀跟拍」。试行条件集中于 `rhythm-report.js` 的 `MASTERY`：3 个不同回合，每回合命中率 ≥85%、有效输入比例 ≥85%、命中平均绝对偏差 ≤一拍的 8%（96 BPM 下为 50ms）。必须是完整的当前四分音符计划，时间数据可靠且与游戏成绩一致。按键与麦克风独立累计，混合输入不累计。重复收藏同一回合不重复计数；缺少时间轴的历史作品不追溯补发。

成长卡显示输入方式、速度、日期与三次达标报告入口。它是项目内的进步记录；此阈值还未经过儿童教学实测校准，不代表外部认证或课程资质。后续新节奏须有实际练习、节奏计划 ID、各自评价标准和回归验证才能开放。

## 本地保存

继续使用 `lets-clap-v1`。新增 `practiceRuns` 自动保存完成作品的原始数据和报告，收藏仍由孩子主动操作；原 `tracks`、标题、拍点与音频保留。报告回填同步到已收藏作品。记录限于当前浏览器，无账户、云同步或防篡改认证。

## 验证范围

42 项当前练习、报告与整合 Node 测试通过，包括目标拍点匹配、提前/滞后/无输入、掌握门槛、来源隔离、历史兼容、重复回合、乱序异步回填、失败重试、HTTP 与模型响应模拟。

浏览器使用独立测试上下文，真实运行一轮 30 秒游戏并定时自动按键，命中 12/48；另用三个明确的合成回合验证成长卡。自动化数据不代表孩子真实学习效果。报告分析中收藏、失败重试、刷新持久化、390px 布局与继续练习入口均由本地浏览器验证；截图与结果保存在工作区 `lets-clap-review/rhythm-feedback-20261011-1711/`，独立验证脚本位于 `/tmp/lets-clap-report-smoke/`。没有新增真人麦克风、真实千问或生产验收。

## Mio 新入口承接

并行整合将 Mio 入口设为 `/`，练习与报告位于 `/practice.html`，新 `server/index.js` 转接报告 API。新服务下已用独立合成记录验证入口加载、报告请求、保存回填与手机弹窗；另以 72 BPM、5 个带休止目标的合成 Mio 交接方案实际运行游戏，完成后自动报告保留 5 个原目标，且未授予均匀跟拍成长卡。完整 Mio 语音/孵化链路由整合聊天继续验收。

编排节奏的报告使用实际目标时间轴，建议保留长短和休止；不计入当前固定 96 BPM 均匀跟拍成长卡。麦克风建议不作未经设备延迟校准的确定早晚评价。
