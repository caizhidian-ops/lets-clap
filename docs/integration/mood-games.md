# 情绪与节奏关卡整合

2026-10-11 用户最终映射：平静 → 悠悠（whale.glb）→ 风车；开心 → 蹦蹦（penguin.glb）→ 跳绳。兴奋没有指定关卡，当前不显示快捷选项，语音/打字提到兴奋时说明未开放，不擅自匹配。腊肠狗资产保留。

主入口 `/`。在同一大场景中先对话、选择心情，再开始游戏；完成后接试听、保存、可改名专辑墙和勋章。旧 `lets-clap-v1` 作品保持原样。

- 平静风车：复用 `escape-world.js` 的长路、风车刹车玩法，加 `calm` 选项；使用生成的鲸鱼、柔和天空、慢速八拍和舒缓背景音乐。原 `/night-rescue.html` 仍是独立夜行关停版，默认效果保留。
- 开心跳绳：生成的企鹅与 `plush-fur.js` 细绒材质；风车室内大场景。`jump-rope-engine.js` 进行十六拍判定（±180ms），绳子在提示拍之后 180ms 到达脚下，起跳动画持续 440ms。连跳、提前/滞后、绊绳、最长连跳和重试均可交互。空格或大按钮起跳，语音用于推进关卡。当前是点击/键盘练习，不是身体动作或真实拍手检测。
- 绳子几何每帧更新顶点，音乐、绳圈和拍点共用 AudioContext 时钟；模型为静态 GLB，起跳是整体模型位移，并非骨骼动画。
- 两个模式复用 `night-music.js` 合成音源，分别使用开心/平静音列，音乐开关可独立控制。
- 收藏成功跳绳后点亮「跳绳达人」。大风车歌曲勋章仍要求正式 `songId` 与通关数据，不由练习生成。

实现入口：`flow.js`；固定映射 `flow-model.js` 的 `gameForMood()`；控制器 `interior-session.js`；跳绳场景 `interior-world.js`；平静风车仍在 `escape-world.js`。正式音频接入继续使用 `LetsClapPlayback.setResult()`，当前试听为输入拍点合成的小鼓。

验证：17 项 Node 测试通过。浏览器实际操作验证鲸鱼风车 8/8 后停转、企鹅跳绳 16/16 和最长连跳 16、模型来源、背景音乐开关、试听/收藏及跳绳勋章；另核对手机布局。定时输入来自自动化测试，不是孩子的真实体验结果。真实语音、真实拍手/运动检测、正式歌曲音频、真实千问均未验收；未部署生产。
